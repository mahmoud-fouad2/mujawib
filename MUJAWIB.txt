1. تعريف المنتج والقرار النهائي
القرار التنفيذي
MUJAWIB ليس Voice Bot Builder ولا SaaS مفتوحًا للتسجيل الذاتي. هو منصة B2B مُدارة لتشغيل موظفي استقبال وخدمة عملاء صوتيين بالعربية، يجهزهم فريقنا ويختبرهم قبل النشر، بينما يحصل العميل على لوحة تشغيل ومراقبة وتقارير سهلة.

الوعد الأساسي
“أفضل تجربة استقبال صوتي عربي يمكن تشغيلها داخل شركة حقيقية — مع إعداد Agent مضبوط، نطق ولهجة واختبارات، وربط فعلي بالحجز والأنظمة.”
المشكلة التي نحلها
•  الصوت العربي لدى كثير من الحلول يبدو آليًا أو غير مستقر مع اللهجات والـ code switching.
•  إعداد الـAgent يعتمد غالبًا على Prompt حر؛ فينتج Agents مختلفة الجودة وغير قابلة للضبط.
•  العميل التجاري لا يريد أن يتعلم SIP وPrompt Engineering وTool Schemas؛ يريد نتيجة تشغيلية.
•  لوحات Voice AI المعتادة تعرض Metrics تقنية أكثر مما تعرض نتيجة العمل: حجز، تحويل، حل الطلب، فشل التكامل.
التميّز
المحور	ما الذي نملكه
Arabic Voice Quality	Arabic Profiles + Pronunciation + QA datasets + production feedback loop
Agent Quality	Agent Factory + Prompt Compiler + Flow rules + publish gate
Operations	Calls + outcomes + bookings + QA + integration health in one console
Managed Delivery	فريقنا يجهز ويختبر وينشر؛ العميل يراقب ويطلب التعديلات
Infrastructure	SIP + موديل Realtime واحد، دون بناء media stack كامل

2. الاسم والهوية المقترحة
الاسم الرئيسي: MUJAWIB — مُجاوِب
•  المعنى: الشخص/النظام الذي يجيب ويتجاوب؛ مباشر وواضح للسوق العربي بدون أن يكون “VoiceAIPro” عامًا.
•  اللفظ: Mu-ja-wib. يصلح كـ wordmark إنجليزي مع استخدام «مُجاوِب» كهوية عربية ثانوية.
•  الـTagline العربي: «صوت عربي يفهم ويُنجز».
•  الـTagline الإنجليزي: “Arabic voice that gets work done.”
حالة الاسم
البحث العلني حتى 10 أغسطس 2026 لم يُظهر منصة AI/Voice معروفة باسم MUJAWIB. النطاق mujawib.com مُسجل حاليًا وحالته pendingDelete، لذلك لا نعتبره متاحًا للحجز الآن. لم يظهر في البحث العلني تسجيل واضح لـ mujawib.ai أو getmujawib.com؛ يُستخدم أحدهما كخيار حجز أولي فقط بعد التحقق لحظة الدفع، مع فحص العلامة والاسم التجاري رسميًا قبل الاعتماد.

بدائل احتياطية لا تعتمدها قبل فحص الحجز الرسمي: MAHKI / QAWLI / MASMOO — لكن لكل منها تشابهات أو استخدامات عامة، لذلك MUJAWIB هو الأنظف من البحث الأولي.
 
3. فلسفة UX/UI — تصميم 2027 بدون تقليد
الهدف ليس نسخ ChatGPT أو Claude أو Gemini. نأخذ منهم أنماط UX الناضجة ونحوّلها إلى Operations Console صوتي.
المبدأ	التطبيق في MUJAWIB
Calm Shell	شريط جانبي ثابت، مساحة عمل هادئة، لا Bento Grid في كل صفحة.
Contextual Inspector	لوحة جانبية يمين الشاشة لخصائص العنصر الحالي بدل فتح صفحات إعدادات متكررة.
Command Surface	بحث عالمي + Cmd/Ctrl+K للتنقل، الاتصال، فتح عميل أو Agent أو Call.
Progressive Disclosure	المستخدم يرى الأساسيات أولًا؛ Technical details تظهر فقط للأدمن المتقدم.
Live Motion with Purpose	حركة waveform/status فقط للمكالمة الحية وحالة التنفيذ؛ لا مؤثرات للزينة.
AI-native assistance	Ask Mujawib داخل لوحات التحليل: “لماذا زادت التحويلات للبشر هذا الأسبوع؟”
RTL-first	العربية ليست ترجمة بعدية؛ layout، direction، numbers، mixed text كلها مصممة من البداية.
Dense when needed	صفحات المراقبة والجداول كثيفة لكن قابلة للمسح السريع؛ صفحات الإنشاء واسعة وهادئة.

قاعدة تصميم
أقل عدد ممكن من الصفحات، وأكثر قدر ممكن من السياق داخل نفس الشاشة. List → Detail → Inspector هو النمط الأساسي.

15. Conversation Flows — منطق واضح بدون Node Spaghetti
الـFlow editor في V1 ليس Canvas حرًا مثل أدوات automation. نستخدم مراحل مرتبة وقابلة للسحب مع شروط بسيطة؛ هذا أسهل للأدمن وأقل أخطاء.
Flow	Required fields	Action	Fallback
Booking	service, date/time; branch/staff إذا لزم	check availability → create booking	callback or transfer
Reschedule	booking/customer + new preference	find → check → update	human
Information	topic / service	structured knowledge	knowledge gap ticket
Lead	name, phone, interest	create lead	save callback
Transfer	department/reason	transfer call	callback request

•  لو المستخدم أعطى 4 حقول في جملة واحدة، لا يعيد الـAgent سؤالها.
•  Offer max 2–3 options صوتيًا؛ القوائم الطويلة سيئة عبر الهاتف.
•  كل Flow له Success/Failure/Abandon outcome صريح للتحليل.

28. Model Policy
Launch default: GPT-Realtime-2.1 مع reasoning منخفض لمعظم مكالمات الاستقبال، ثم نثبت السلوك عبر snapshot/version عندما يكون ذلك مناسبًا. Mini لا يدخل launch path قبل benchmark يثبت أن الجودة العربية لا تتراجع.
•  موديل واحد في كل مكالمة، Audio ↔ Audio.
•  لا STT + LLM + TTS cascade في V1.
•  لا model picker للعميل.
•  أي تغيير موديل مستقبلي يمر عبر Voice Adapter داخلي وليس إعادة بناء المنتج.
 
29. Security, Privacy & Operational Controls
•  Tenant isolation في قاعدة البيانات وسياسات الوصول.
•  Credentials لا تظهر في client UI؛ secrets في managed secret store.
•  Audit log لكل Publish / integration change / phone route / user permission.
•  Recording/transcription configurable per client and jurisdiction; يحتاج مراجعة قانونية محلية قبل الإطلاق في كل دولة.
•  Retention policy per workspace: calls/events/recordings/docs.
•  Optional PII masking في analytics/export.
•  Role-based access + least privilege.
•  Emergency kill switch: disable agent / route calls to fallback human destination.
